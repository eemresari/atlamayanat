## About

I build **interactive, AI-powered physical experiences** — science-center exhibits where computer vision, local LLMs and projection-mapped games meet real visitors.

These are not demos: each exhibit runs unattended as a kiosk, works fully offline, recovers from its own errors, and ships as a **licensed Windows installer** (Nuitka standalone build + Inno Setup, offline license keys signed by a separate key-management tool).

- **Computer vision in production** — MediaPipe hand tracking, OpenCV contour detection, camera–projector homography and lens calibration, calibration wizards for on-site setup
- **Local-first AI** — conversational exhibit on a local 4B LLM (Ollama · Qwen3), Whisper speech-to-text, offline Turkish TTS
- **Real-time web front ends** — WebSocket bridges from Python to browser renderers (WebGL2, matter.js)
- **Mobile & ML** — React Native + Expo app, LSTM blood-glucose forecasting with TensorFlow Lite export
- **Game development** — Unity 6 (URP 2D), pattern-driven Python game engine
